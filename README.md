# Lily

An open-source platform for hosting and managing game servers, starting with Minecraft. Customers sign up on the hosted site, create a server, and manage it from the browser. Paid tiers are priced at what the infrastructure costs.

**Status: early.** Nothing runs yet. See [`ROADMAP.md`](ROADMAP.md) for what is being built now and what comes later.

Lily is written and maintained mostly by coding agents, with humans deciding what the product does. The rules they follow are in [`AGENTS.md`](AGENTS.md), and the pipeline from request to merged change is in [`process/`](process/).
